## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/chaishillomnitech1/Galactic-Frequency-Broadcaster-.git
cd Galactic-Frequency-Broadcaster-
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm start
```

4. Open your browser and navigate to:
```
http://localhost:3000
```

## 🎮 Usage

1. **Select a Frequency**: Choose from pre-configured healing frequencies or enter a custom frequency
2. **Adjust Volume**: Use the volume slider to set comfortable listening levels
3. **Choose Waveform**: Select the waveform type (sine recommended for pure tones)
4. **Start Broadcasting**: Click the "Start Broadcasting" button to begin frequency generation
5. **Monitor Dashboard**: View real-time metrics including current frequency, session duration, and resonance tracking
6. **Stop Broadcasting**: Click the "Stop" button to end the session

## 🌐 Multi-Platform Support

The broadcaster automatically detects your platform:
- **Web**: Works on all modern browsers supporting Web Audio API
- **Mobile**: Responsive design for smartphones and tablets
- **VR/XR**: Compatible with WebXR-enabled devices and browsers

## 🔧 Technical Details

### Web Audio API
The application uses the Web Audio API for real-time audio synthesis:
- `OscillatorNode`: Generates frequency waveforms
- `GainNode`: Controls volume/amplitude
- `AnalyserNode`: Provides real-time waveform visualization

### Browser Compatibility
- Chrome/Edge: Full support
- Firefox: Full support
- Safari: Full support (iOS 14.5+)
- Opera: Full support

### VR/XR Integration
The application detects WebXR support and indicates VR/XR compatibility through:
- Platform detection via `navigator.xr`
- Immersive VR session support checking
- Multi-dimensional broadcasting visualization

## 📊 Dashboard Metrics

- **Current Frequency**: Real-time display of broadcasting frequency
- **Broadcasting Status**: Active/Inactive state with visual indicators
- **Session Duration**: Elapsed time since broadcasting started
- **Platform Info**: Current platform (Web/Mobile/VR)
- **Waveform Visualization**: Real-time visual representation of the audio signal
- **Galactic Sync**: Connection status to Omniverse Protocol
